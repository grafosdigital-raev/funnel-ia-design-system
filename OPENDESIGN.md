# OpenDesign Integration Guide

## Purpose
Use this repository to seed and refine the Funnel-IA design system in OpenDesign.

## Recommended input

### GitHub or website
Use the repository URL:

https://github.com/grafosdigital-raev/funnel-ia-design-system

### DESIGN.md
OpenDesign should consume the repository's root `DESIGN.md` as the primary visual contract.

### Additional material
Add only approved public-safe assets:
- Funnel-IA logo;
- approved screenshots;
- approved public references.

## Brand description
Funnel-IA is a Latin American strategy, design and digital operations firm that turns valuable businesses into systems that are easier to see, understand, sell, serve and evolve, with AI working behind the experience.

Personality: clear, human, calm, strategic, premium, contemporary, curious and concrete.

Experience: editorial when it explains; cinematic when it reveals.

Core visual principle: **80% life / 20% technology.**

Avoid generic agency layouts, robot/AI clichés, excessive gradients, neon overload, repetitive card grids and technology presented as the protagonist.

## Governance
OpenDesign may propose refinements.
Approved refinements must be written back into this repository before they become canonical.

## Acceptance checklist
A generated system should:
- preserve core palette;
- use Inter + restrained Playfair Display Italic;
- feel premium without intimidation;
- foreground people/business/results;
- support editorial light and premium dark modes;
- avoid AI clichés;
- remain mobile-first and accessible;
- produce reusable rather than one-off patterns.
