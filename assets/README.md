# Brand Assets

This folder is for approved, public-safe Funnel-IA visual assets.

## Intended contents
- logos;
- marks;
- approved icons;
- approved public illustrations;
- approved public photography;
- optimized web variants.

## Rules
- Do not redraw or distort the logo.
- Preserve aspect ratio.
- Prefer SVG where appropriate.
- Optimize raster assets for web delivery.
- Do not commit proprietary font files.
- Do not commit client-confidential assets.
- Do not commit secrets or metadata that exposes private systems.
