# Component Catalog

This folder governs reusable UI components. Components should inherit tokens and UX principles rather than create local mini-design systems.

## Initial catalog
- Buttons
- Links
- Navigation
- Form fields
- Selects
- Checkboxes/radios
- Cards
- Dialogs
- Tabs/accordions
- Status indicators
- Testimonial/proof blocks
- Pricing/offer blocks
- CTA blocks

## Component rules
- Minimum interactive target: 44×44 px where applicable.
- Visible keyboard focus.
- Accessible labels and states.
- Spanish customer-facing language.
- One primary action per decision area.
- Secondary actions must be visually subordinate.
- Never use disabled-looking styling for available actions.
- Prefer content hierarchy over excessive containers.
