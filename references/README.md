# Approved References

Use this folder for approved, public-safe visual references.

## Allowed
- Funnel-IA screenshots approved for sharing;
- approved public URLs;
- logo usage examples;
- component examples;
- photography direction examples with clear rights/source;
- before/after design-system examples.

## Not allowed
- confidential client material;
- private dashboards;
- credentials or environment screenshots;
- internal session notes;
- unapproved client names/logos;
- copyrighted assets without permission.

## Rule
References are evidence, not automatic standards.
A reference becomes governing only when its principle is documented in DESIGN.md, a token file, a component file or a pattern file.
