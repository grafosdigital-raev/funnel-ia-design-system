# Pattern Catalog

Patterns combine components into repeatable marketing and product experiences.

## Governing patterns
- Hero
- Problem/opportunity
- Editorial explanation
- Cinematic reveal
- Four-door solution architecture
- Diagnostic/discovery
- Conversational CTA
- Social proof/evidence
- Process/method
- Pricing/offer
- FAQ
- Final CTA
- Form/onboarding
- “Life continues / system continues” narrative

## Conversion flow
Atracción → Conversación → Diagnóstico → Discovery → Propuesta → Producción → Entrega → Seguimiento → Evolución

## Pattern rule
A pattern must do at least one:
- clarify;
- demonstrate;
- personalize;
- reduce friction;
- create trust;
- advance conversion.

If it does none of these, it is decoration and should be reconsidered.
