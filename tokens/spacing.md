# Spacing Tokens

Use a simple 4px base rhythm.

- space-1: 4px
- space-2: 8px
- space-3: 12px
- space-4: 16px
- space-5: 24px
- space-6: 32px
- space-7: 48px
- space-8: 64px
- space-9: 96px
- space-10: 128px

## Rules
- Favor generous negative space.
- Section spacing should support one dominant idea, not compress multiple ideas together.
- Mobile may reduce section spacing, but not to the point of losing hierarchy.
- Prefer spacing tokens over arbitrary values.
