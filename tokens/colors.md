# Color Tokens

## Core
| Token | Value | Use |
|---|---|---|
| color.obsidian | #02050D | Premium dark backgrounds |
| color.night | #06111F | Secondary dark surfaces |
| color.paper | #F7F8FA | Editorial light backgrounds |
| color.ink | #101114 | Primary text on light |
| color.white | #FFFFFF | Primary text on dark |
| color.text.secondary.light | #5E6470 | Secondary text on light |
| color.text.secondary.dark | #A7B0C0 | Secondary text on dark |
| color.cyan | #00D5E6 | Signal, accent, ambient light |
| color.blue | #2979FF | Primary technology accent |
| color.green | #16C784 | Action/success signal |

## Usage ratios
### Editorial light
70% paper/white · 20% ink · 7% blue/cyan · 3% green.

### Premium dark
70% obsidian/night · 15% blue/cyan ambient light · 10% white · 5% green.

## Rules
- Magenta is legacy, not governing.
- Accent color communicates priority or state; it is not decorative filler.
- Preserve WCAG AA contrast for text and controls.
