# Funnel-IA Design System

Public-safe canonical design system for **Funnel-IA**.

## Purpose
This repository defines the visual language, UX principles, tokens, reusable components and marketing patterns used across Funnel-IA websites, landing pages, product experiences, presentations and other approved digital assets.

## Governing principle
**GitHub is the versioned source of truth.**

OpenDesign, code generators and AI agents may consume this repository to create or refine artifacts, but they do not replace the canonical system. Approved changes return here through versioned commits.

## Signature
**Editorial when it explains. Cinematic when it reveals.**

Core visual rule: **80% life / 20% technology.**

## Brand position
Funnel-IA does not sell “AI for AI’s sake”. It builds useful digital capacity: presence, conversion, attention, follow-up and connected operations.

## Security / publication boundary
This repository is intentionally safe to share publicly.

Never commit:
- passwords;
- API keys;
- access tokens;
- PINs;
- credentials;
- `.env` contents;
- client-confidential data;
- private infrastructure details;
- internal governance/session material;
- restricted prompts.
